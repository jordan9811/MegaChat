## Landed (all seven)

1. **Human-readable payment errors.** Known `InsufficientBalance` reverts →
   one sentence ("Not enough balance — you have X, this costs Y") in the
   viewer's own mode (credits / USDC) + an [Add funds] action; amounts parse
   from the revert's values line (signature-line `uint256` decoys excluded),
   with a live-balance + known-cost fallback when a revert carries no args.
   Unknown walls → short generic + collapsible "Technical details" holding
   the raw error. Short app-level errors pass through untouched. Wired into
   the join catch, MegaChat send catch, and the mid-session tick-failure
   banner. Display only — transaction logic untouched.
2. **Free-room checkbox.** Explicit state: only the user's click (or opening
   a room that IS free) sets it. Empty/garbled price = invalid → inline
   "Enter a price — or flip 💸 Free room", create disabled. Bonus guard:
   autosave (managing) skips invalid prices, so backspacing mid-edit can
   never write an empty price over a live room. Checking free still hides
   the price box.
3. **Mic centering + OG.** The art's canvas has transparent RIGHT padding
   (glitch confetti) — its alpha-mass sits 4.4% left of center, so centered
   CSS looked off. Fix: `translate: 4.5% 0` on the visual (standalone
   property — composes with the reveal/float transform animations).
   Measured via `_diag-mic-bbox.mjs`; gate asserts mass-center ±8px at
   375px and 1280px (actual: ~1px). New `web/public/og.png` (1200x630, mic +
   wordmark + tagline + equation) generated by `scripts/generate-og.mjs`;
   og/twitter meta updated (old card was the 697x985 portrait hero).
4. **Landing actions.** Hero = How it works · Start a room · GRAB 10 SEC.
   "Browse rooms" left the hero and joined the shared nav (`/#browse`) —
   the directory itself is untouched.
5. **Account layer in dashboard.** Sections: **Rooms | Account | Defaults**
   (deep-linkable `?section=`). Account: handle-as-room-link (copyable),
   balance + address, linked accounts (raw Privy REST — the SDK drops
   twitch/x; legacy single-provider identities list their one provider).
   Defaults: stored server-side ON THE IDENTITY (`identities.json`,
   survives browsers/devices) via `GET/PUT /api/account/defaults`; "Save
   current create-form as my defaults" + Clear; a fresh dashboard's create
   form starts from saved defaults — pristine forms only, a touched draft
   is never clobbered. Header chip menu gained "Account" and the handle
   line links there.
6. **Delay copy.** Every user-facing "~15s behind" → "slight delay"/"a touch
   behind" (join labels, how-it-works copy + SVG + aria, booth description,
   settings hint, MegaChat sent/playing toasts). Gate asserts zero
   15-second claims in rendered landing/join/how-it-works text.
7. **Landing copy.** Simple: "Viewers pay per second to put their camera in
   your live broadcast." (exact spec sentence); Advanced keeps USDC with the
   same in-your-broadcast fix. Equation line — "Call-in show + FaceTime +
   Superchat = MegaChat" — sits under the CTAs as a styled brand moment
   (neon operators, lime glow on the mark).
