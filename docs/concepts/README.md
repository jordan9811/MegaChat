# Concepts

The handful of ideas every feature page assumes you already have. Each is one page, each names the file that makes it real.

| Concept | One line |
|---|---|
| [Rooms and seats](rooms-and-seats.md) | A room is a streamer's configured space; a seat is one viewer's metered place on camera inside it. |
| [MegaChats](megachats.md) | A short recorded clip a viewer pays to have played on the stream once. |
| [The overlay](the-overlay.md) | One OBS browser source that draws seats, MegaChats and the verification badge. |
| [Identity and handles](identity-and-handles.md) | Who a person is to MegaChat (a platform login), and the name a room lives at. |
| [Money and metering](money-and-metering.md) | Per-second charging, what is locked, what refunds, and which chain does it. |
| [Bounties](bounties.md) | Money fans pool on a streamer's name, claimable by going live with the program on. |
| [Airings and evidence](airings-and-evidence.md) | What the system remembers about a broadcast after it ends, and why two records exist. |
