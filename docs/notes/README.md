# Notes

This directory is yours.

Write anything here, from GitBook's editor or from a text editor: half-formed ideas, a page you want to come back to, a rant, a decision you have not made yet. There are no rules in this directory — no citation requirement, no status tags, no "what this does NOT do" section.

Nothing automated touches it:

- `npm run docs:check` skips it entirely.
- `npm run docs:sync` never reads or writes it.
- `npm run docs:summary` will *add* a page you create here to the table of contents so GitBook shows it, but never rewrites, reorders or removes one.

The only thing that has to be true is that a page you create ends up listed in `docs/SUMMARY.md`, or GitBook will not display it. Running `npm run docs:summary` does that; so does adding a line by hand.
