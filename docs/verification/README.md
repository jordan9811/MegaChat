# Verification

The central claim of the bounty program is that a streamer is paid only for MegaChats that actually aired on their broadcast. This section states what that claim rests on, what each piece of evidence proves, and what none of them prove.

It is written for someone deciding whether to trust a payout — or to dispute one — and it is deliberately not marketing. Every mechanism named here is cited to the file that implements it.

- **How a bounty is verified** — below, on this page.
- **Limitations** — the things verification cannot see, with what is done about each.

{% hint style="warning" %}
Pre-launch. The pipeline below has been run against synthetic fixtures, local stubs, and a small number of real broadcasts by the project's own operator. It has never scored a paying stranger's stream. Source: `docs/internal/launch-readiness.md`.
{% endhint %}
